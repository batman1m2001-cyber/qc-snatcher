## Goal

qc-snatcher scores Vietnamese collection-call transcripts for QC. For each call it detects compliance violations (HVC) and agent or customer sentiment, and writes one JSON verdict. It is built as operonx LLM graphs, run per call in pods behind a deploy-time selfcheck gate.
