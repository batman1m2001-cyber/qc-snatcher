The problem01 / 08

Screening 15,000–30,000 collection calls a day for compliance

Cost of a false alarm

QC time spent on a clean call. If the flag survives review, an agent carries a mark for something that did not happen.

Cost of a miss

Compliance exposure — and it is silent. No queue entry, no record, no signal that anything was missed.

Cost of slow rules

QC owns the judgement but not the rulebook. Every correction they want is a development and release cycle.

How it was measured

QC selected 334 calls from 21–25 Aug 2026 and adjudicated both environments, run in parallel, on that same set. QC identified 98 as containing a violation — the reference point for both sides.

Same calls, same adjudicator. The difference is attributable to the architecture, not to data or grading.

Per-1,000 figures are scaled from that set, which QC selected and which is not a random sample of live traffic. Direction and relative magnitude hold; absolute volumes will differ.

Monitoring after go-live — QC’s own proposals

1 · System. Retain the list of calls the filter excluded, retrievable by QC.

2 · System. Surface, with priority, calls carrying high or critical indicators that were not flagged.

3 · QC. Sample the excluded set periodically, measure the true miss rate, feed it into the next tuning round.

4 · Both. Track false alarms and missed violations separately. No single combined score.

Question for the board. This time both numbers fell together, so no trade-off was required. That will not hold in the next tuning rounds: from here, reducing one raises the other. The board is asked to set the priority between reducing unnecessary review and reducing missed violations, as the stated basis for tuning.
